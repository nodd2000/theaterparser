## Справочник театров для карты источников

1. **Wikidata** (SPARQL): театры в России, город, сайт, координаты, иногда Telegram-аккаунт
   (свойство P3789). Бесплатно, открытая лицензия.
2. **Культура.РФ** (culture.ru/institutes): каталог учреждений культуры с адресами и сайтами.
3. Ручные правки в админке.
